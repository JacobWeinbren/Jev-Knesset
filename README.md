# Knesset speech on the Chapel Hill scales

Every Knesset speech from 1992 to July 2026, scored by TypeSafe's Jev on the Chapel Hill Expert Survey's Israel scales
and on a set of speech-level questions (subjects, tone, heckles), then averaged to members, parties and blocs. The
write-up is at https://kafkaesque.blog/llm-knesset/. Running python -m knesset_ches.cli lists the steps.
