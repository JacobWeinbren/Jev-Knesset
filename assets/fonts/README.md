# Fonts

The charts use two typefaces, loaded from this folder when knesset_ches.blog_style is imported: Newsreader
(Production Type) for headlines, subtitles and notes, and Instrument Sans (Instrument) for labels, ticks and footers.
They were downloaded from Google Fonts on 23 September 2026 and are under the SIL Open Font License 1.1, a copy of
which is in each folder. Neither covers Hebrew, so Hebrew text falls back to Arial Hebrew.
